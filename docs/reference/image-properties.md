# Image properties

Image Properties controls the appearance of the circular plot without rerunning BLAST.

## Title and legend

Enter a plot title in the text field. The **Legend** checkbox controls whether the ring legend is drawn.

## Rings

- **Inner Radius** changes the empty centre of the plot.
- **Ring Width** sets the default width of alignment rings.
- **GC Ring Width** sets the width of GC content and GC skew tracks.
- **Ring Spacing** changes the gap between tracks.

## Fonts

Separate controls are available for legend, scale, title and annotation-label font sizes. Judge font size using the intended output dimensions, not only the on-screen preview.

## Interactive view

Zoom, pan and dragged legend positions are retained in exports. Use **Reset** before exporting if you want the standard centred composition.
