# Ring configuration

Each ring is an independent visual track. Rings appear from the inside out in the order shown in the editor.

| Control | Effect |
|---|---|
| Ring name | Text used in the legend |
| Colour and hex value | Base colour for the ring |
| Upper Threshold | Identity at which the full ring colour is used |
| Lower Threshold | Lowest identity drawn on the ring |
| Ring Width | Optional width override for this ring |
| Labels | Shows or hides annotation labels for the ring |
| Add Files | Adds sequence or graph inputs |
| Custom Ring Overlay | Opens the annotation editor |

## Reordering and deletion

Use the arrow controls to move a ring inward or outward. Removing a ring also removes its file assignments and custom overlay from the current workspace.

## Colour choices

Choose colours that remain distinguishable when printed and when rings use lighter threshold shades. Enter a precise CSS hexadecimal value when matching an existing figure or palette.

## Ring width

Leave **Ring Width** empty to use the global value from **Image Properties**. Use an override sparingly for emphasis or for a graph track that needs more vertical range.
